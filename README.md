# Synthetic_ornithology_results

Static site showing results from EAGLE, the generative audio model behind Synthetic Ornithology: real and generated recordings side by side, along with interesting outputs and failure cases.

Live at https://fred-dev.github.io/Synthetic_ornithology_results/

- `index.html` / `comparison.html`: real and generated pairs (`audio_pairs.json`)
- `interesting.html`: notable generations (`audio_interesting.json`)
- `errors.html`: failure cases (`audio_errors.json`)
- `configs/`: the model config and prompt template used
- `audioSamples/`: the audio
